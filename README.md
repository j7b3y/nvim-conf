# Neovim 設定（SSH / CLI 専用環境向け）

> VSCode から移行した人向けに、「何をしたいか」ベースで整理しています。
> この設定は **SSH 接続の CLI 環境**（ブラウザ・GUI が使えないリモートサーバー）での利用を前提に調整されています。
> Linux 全般・Termux でも動くよう、外部ツールが無い環境では該当機能だけを自動で無効化し、Neovim 内蔵機能へフォールバックします。

## セットアップ

前提: **Neovim 0.11 以上**(Termux の `pkg install neovim` で入る最新版で可)。
0.10 以下ではプラグインを読み込まず、`init.lua` の基本設定のみで起動します。

```bash
git clone <このリポジトリ> ~/.config/nvim
nvim
```

初回起動時に **lazy.nvim** の導入と **プラグインの同期**(lazy-lock.json でバージョン固定)が自動で行われます。

### 外部ツールと、無い場合の動き

追加の依存は「必須」にしていません。無い環境では該当機能だけを自動で無効化し、可能なものは Neovim 内蔵機能へフォールバックします。

| ツール | 必須? | 使う機能 | 無い場合の動き |
|---|---|---|---|
| `git` | 必須 | プラグイン取得・Git 連携 | プラグイン導入不可。gitsigns 等は自動で無効化 |
| `curl` + `tar` | 任意 | lazygit 自動導入 | 自動導入をスキップ |
| `rg` (ripgrep) | 任意 | 全文検索 `<leader>sg` / grug-far | 内蔵 `:vimgrep` + quickfix にフォールバック(導入方法を通知) |
| C コンパイラ (`cc`/`gcc`/`clang`) | 任意 | treesitter パーサーのビルド | ビルド・自動導入をスキップ(Neovim 同梱パーサーでハイライト) |
| `lazygit` | 任意 | `<leader>gg` / `<leader>lg` | 自動導入は後述の対応環境のみ。無い場合はキー押下で導入方法を通知 |
| `lua_ls` (LSP) | 任意 | 補完・定義ジャンプ | glibc Linux / macOS では mason が自動導入。それ以外は PATH 上のものだけ有効化 |

- **lazygit の自動導入**は、配布バイナリが動く環境(glibc の Linux x64/arm64・macOS)でのみ実行します。Termux(Android)や musl(Alpine 等)では自動ダウンロードせず、キー押下時に `pkg install lazygit` / `apk add lazygit` などの案内を表示します。
- **mason** は Termux / musl では組み込みません(配布バイナリが動かないため)。それらの環境では `lua_ls` を各パッケージマネージャで入れてください。
- LSP は言語固有の設定を含まない汎用構成です。`lua/plugins/nvim-lspconfig.lua` の `servers` にサーバー名を追加すると、対応環境では mason が `~/.local/share/nvim/mason` へ自動インストールします(システムへのインストールは行いません)。デフォルトは nvim 設定編集用の `lua_ls` のみ。

### Termux

```bash
pkg install neovim git
# お好みで(無くても基本機能は動きます)
pkg install ripgrep fd clang lazygit lua-language-server
```

- ripgrep / fd / clang / lazygit / lua-language-server は Termux の公式パッケージで導入できます。
- `~/.local/bin` を PATH に通しておくと、lazygit 等を手動配置した場合にも拾えます。

## 画面レイアウト（VSCode 風）

```
┌──────────────┬──────────────────┬───────────────┐
│              │  タブバー                          │
│  Explorer    ├──────────────────┤  シェル       │
│  (<leader>e) │  エディタ          │  (右・全高さ) │
│  git状況付き  │  （分割自由）      │  (Ctrl+\)    │
│              │                  │               │
│              │                  │               │
└──────────────┴──────────────────┴───────────────┘
```

- ターミナルはシェルのみ。**右カラム**(約33%幅・縦方向全体)に開きます。
- エージェント連携（opencode 等）はエディタ特化方針のため撤去済みです。
- エディタは通常のウィンドウ分割（`:split` / `:vsplit` / `Ctrl+w` 系）を自由に使えます。

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| エクスプローラー（左サイドバー）を開閉 | `<leader>e` | `Ctrl+B`（サイドバー） |
| タブを移動 | `[b` / `]b` | `Ctrl+PgUp` / `Ctrl+PgDn` |
| タブを選んで閉じる | `<leader>bd` | `Ctrl+W` |
| 単一画面に戻す（余計な分割を閉じる） | `<leader>wo` | なし |
| ウィンドウ間を移動 | `Ctrl+h` `j` `k` `l` | なし（分割間の移動） |
| ウィンドウ幅を均等化 | `<leader>w=` | なし |
| ウィンドウ高さを増減 | `<leader>w+` / `<leader>w-`（±2行） | なし |
| ウィンドウ幅を増減 | `<leader>w>` / `<leader>w<`（±5列） | なし |
| ウィンドウを閉じる | `<leader>wd` または `Ctrl+w q` | `Ctrl+W` |
| 右カラムにシェルを開閉（汎用） | `Ctrl+\` | `` Ctrl+` ``（右ドロワー相当） |
| ターミナルからノーマルモードへ抜ける | `jk` | なし |

- エディタタブは bufferline.nvim で表示されます。Explorer が開いている間はタブバーが右に寄ります。
- シェル（右カラム全高）は `lua/config/terminal.lua` で管理され、開くたびにサイズを掛け直すため手動リサイズ後も仕様に戻ります。

## このマニュアルの使い方

- **キーを忘れたら `Space` を押す** → [which-key](https://github.com/folke/which-key.nvim) が続きの候補を表示します。各行の説明は設定ファイルの `desc` をそのまま拾っているので、常に最新です。
- `<leader>?` … いま開いているバッファで有効なキーマップ一覧
- `<leader>K` … 全キーマップ一覧
- この Markdown は「よく使うものを俯瞰する」ための静的なまとめです。網羅性より読みやすさ優先。

## はじめに：モードの概念（VSCodeにない概念）

nvimにはモードがあります。起動直後は **ノーマルモード** です。

| モード | 入り方 | 何ができる |
|---|---|---|
| ノーマルモード | `Esc` または `jk` | ナビゲーション・コマンド実行（ここが基本） |
| インサートモード | `i` | テキスト入力（VSCodeの通常状態に近い） |
| ビジュアルモード | `v` | テキスト選択 |
| ターミナルモード | `Ctrl+\` の中 | `jk` でノーマル相当（`Ctrl+\` `Ctrl+n`） |

**Leaderキー = `Space`**（以降 `<leader>` と表記）

### ファイラ（oil.nvim）の中での操作

ファイルエクスプローラーは `<leader>e`（サイドバー）と `-`（バッファ型ファイラ）の2系統があります。

ファイラはバッファなので、**普通に編集して保存(`:w`)するとファイル操作が実行されます**（作成・リネーム・削除）。

| キー | 動作 |
|---|---|
| `<CR>` | 開く（ディレクトリなら中へ） |
| `-` | 一つ上のディレクトリへ |
| `_` | カレントディレクトリ(cwd)へ |
| `g?` | ヘルプ（キー一覧） |
| `<C-c>` | ファイラを閉じる |
| `.` で始まる項目 | 隠しファイルも常に表示する設定 |

## コードを検索する

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| プロジェクト全体をGrep検索 | `<leader>sg` または `<leader>fg` | `Ctrl+Shift+F` |
| ヘルプを検索 | `<leader>fh` | なし |
| ファイル内を検索 | `/` （下方向）/ `?` （上方向） | `Ctrl+F` |
| 次の検索結果 / 前の検索結果 | `n` / `N` | `Enter` / `Shift+Enter` |
| カーソル下の単語を検索 | `*` （下）/ `#` （上） | なし |
| 検索ハイライトを消す | `Esc Esc` | なし |

> `rg` (ripgrep) が無い環境では、`<leader>sg` / `<leader>fg` は Neovim 内蔵の `:vimgrep` + quickfix に自動で切り替わります（初回に導入方法を通知）。

### Grep して一括置換（grug-far.nvim）

検索結果がバッファに出るので、**バッファ上でテキストを直接書き換えて反映**できます。`rg` (ripgrep) が必要です（無い場合はキー押下時に導入方法を通知）。

| やりたいこと | キー |
|---|---|
| プロジェクト全体を対象に開く | `<leader>rr` |
| カーソル下の単語で開く | `<leader>rw` |
| 現在のファイルだけを対象に開く | `<leader>rf` |
| 選択範囲の文字列で開く（ビジュアルモード） | `<leader>rr` |

grug-far バッファの中での操作：

| キー | 動作 |
|---|---|
| `<leader>rp` | 置換を実行 |
| `<leader>rs` | バッファの編集内容をファイルへ反映 |
| `<leader>rq` | 結果を quickfix リストへ |
| `<leader>ro` | カーソル位置の該当箇所を開く |
| `<leader>rc` | 閉じる |
| `<leader>rt` | 検索履歴を開く |

## ターミナル・Git

### ターミナル

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| 右カラムにシェルを開閉（汎用） | `Ctrl+\` | `` Ctrl+` ``（右ドロワー相当） |
| ターミナルからノーマルモードへ抜ける | `jk` | なし |
| ターミナルの高さを変える | `<leader>w+` / `<leader>w-`（フォーカス後に実行） | なし |
| ターミナルの幅を変える（右カラム用） | `<leader>w>` / `<leader>w<`（フォーカス後に実行） | なし |

- 右シェルの幅は約33%列（全高）に固定です（開くたびに掛け直すため、手動リサイズ後も次回開閉で戻ります。`lua/config/terminal.lua` で変更可）。
- ターミナル窓の上部（winbar）に `TERMINAL` と表示されます。フォーカス中の窓は色が変わるので判別できます。
- ターミナル窓は背景が少し明るく、窓の境は白線（`WinSeparator`）のため、エディタとの区別が付きます。ステータスラインは最下部に1本化（`laststatus=3`）しているため、横の境も白線です。
- その他のリサイズ手段: `:<数字>resize`（例 `:resize 30`）、`Ctrl+w` `+` / `-`、`<leader>w=`（均等化）。

### Git（gitsigns.nvim）

エディタ左端に変更行が表示されます（`▎` 追加 / `~` 変更 / `_` 削除）。

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| 変更一覧（Source Control）を表示 | `<leader>gS` | Source Controlパネル |
| 次の / 前の変更（hunk）へ | `]h` / `[h` | なし |
| hunkをステージ | `<leader>hs` | `+` ボタン |
| hunkを元に戻す | `<leader>hr` | `↩` ボタン |
| ファイル全体をステージ | `<leader>hS` | なし |
| ステージを取り消し | `<leader>hu` | なし |
| hunkをプレビュー | `<leader>hp` | なし |
| blame を表示 | `<leader>hb` | GitLens |
| 前回との diff を表示 | `<leader>hd` | なし |

### lazygit

| やりたいこと | キー |
|---|---|
| lazygit を開く（Snacks） | `<leader>gg` |
| lazygit を開く（lazygit.nvim） | `<leader>lg` |

lazygit は初回起動時に `~/.local/bin` へ自動導入されます（要ネットワーク）。ただし配布バイナリが動く **glibc の Linux (x64/arm64) と macOS のみ**で、Termux / musl (Alpine 等) では自動導入せず、キー押下時に `pkg install lazygit` などの案内を表示します。手動で入れたい場合は任意のバイナリを `~/.local/bin/lazygit` に置いてください。

### GitHub 連携

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| 現在のファイルをGitHubで開く | `<leader>gf` | なし |
| 選択行をGitHubでハイライト表示 | `<leader>gf`（ビジュアルモード） | なし |
| GitHubリポジトリのトップを開く | `<leader>gr`（ノーマルモード）| なし |
| GitHubでブラウズ（ブランチ選択あり） | `<leader>gB` | なし |

> SSH環境ではブラウザを起動できないため、`gx` は URL を `+` レジスタにコピーして通知します（ローカル側に手動で貼り付けて開く運用向け）。

## Vim / Neovim の標準キー（設定不要・よく使うもの）

プラグインではなく Vim 本体の機能。詳細は `:help quickref`（vimdoc-ja 導入済みなので日本語）。

### 移動（ノーマルモード）

| キー | 動作 |
|---|---|
| `h` `j` `k` `l` | 左 下 上 右 |
| `w` / `b` | 次の単語の先頭 / 前の単語の先頭 |
| `e` | 単語の末尾 |
| `0` / `^` / `$` | 行頭 / 行の最初の非空白 / 行末 |
| `gg` / `G` | ファイルの先頭 / 末尾 |
| `{` / `}` | 段落単位で上 / 下 |
| `%` | 対応する括弧へ |
| `Ctrl+u` / `Ctrl+d` | 半画面 上 / 下スクロール |
| `f{文字}` / `t{文字}` | 行内でその文字へ / その手前へ |
| `{数字}G` または `:{数字}` | 指定行へ |
| `H` / `M` / `L` | 画面の 上 / 中央 / 下へ |

### 編集（ノーマルモード）

| キー | 動作 |
|---|---|
| `i` / `a` | カーソル前 / 後ろ から挿入 |
| `I` / `A` | 行頭 / 行末 から挿入 |

| `cw` / `ciw` / `ci"` | 単語を変更 / 単語まるごと変更 / `"` の中を変更 |

| キー / コマンド | 動作 |

| `:bn` / `:bp` / `[b` / `]b` | 次 / 前 のバッファ |
| `:bd` | バッファを閉じる |
| `:tabnew` / `gt` / `gT` | 新規タブ / 次タブ / 前タブ |

### ビジュアルモード

| キー | 動作 |
|---|---|
| `v` / `V` / `Ctrl+v` | 文字選択 / 行選択 / 矩形選択 |
| `y` / `d` / `c` | 選択範囲を コピー / 削除 / 変更 |
| `>` / `<` | 選択範囲をインデント 増 / 減 |
| `=` | 選択範囲を自動整形 |

> マウスはクリックでのカーソル移動とホイールスクロールのみ有効です。マウスドラッグで選択（ビジュアルモード）は始まらない設定です（誤クリックで選択がついてくるのを防ぐため）。選択は `v` / `V` / `Ctrl+v` で開始してください。

## ファイル構成

```
~/.config/nvim/
├── init.lua                  # エントリーポイント（基本オプション・キーマップ）
├── lazy-lock.json            # プラグインのバージョン固定
└── lua/
    ├── config/
    │   ├── lazy.lua          # lazy.nvim のブートストラップ（0.10 以下は基本モード）
    │   ├── env.lua           # 実行環境・外部ツールの検出（Termux/musl/glibc）
    │   ├── layout.lua        # ウィンドウ移動・リサイズ（分割は自由）
    │   ├── lazygit.lua       # lazygit の自動導入（対応環境のみ）
    │   ├── session.lua       # セッション管理（Neovim 内蔵のみ）
    │   └── terminal.lua      # 右カラム汎用ターミナルの操作
    └── plugins/              # プラグインごとの設定（1ファイル1プラグイン）
```
