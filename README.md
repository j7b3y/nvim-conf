# Neovim 設定（SSH / CLI 専用環境向け）

> VSCode から移行した人向けに、「何をしたいか」ベースで整理しています。
> この設定は **SSH 接続の CLI 環境**（ブラウザ・GUI が使えないリモートサーバー）での利用を前提に調整されています。

## セットアップ

```bash
git clone <このリポジトリ> ~/.config/nvim
nvim
```

これだけで完了です。初回起動時に以下が自動で行われます。

1. **lazy.nvim**（プラグインマネージャ）の自動インストール
2. **全プラグインの自動同期**（lazy-lock.json でバージョン固定）
3. **lazygit の自動導入**（`~/.local/bin/lazygit` に v0.65.0 の静的バイナリをダウンロード。ディストリビューション非依存）

必要な外部ツール（システムにインストール不要）：

| ツール | 用途 | 備考 |
|---|---|---|
| `git` | 必須 | ほぼ必ず導入済み |
| `rg` (ripgrep) | 全文検索 `<leader>sg` | 無い場合は grep 検索のみ不可 |
| `curl` / `tar` | lazygit 自動導入 | 初回のみ |
| `make` / `gcc` | 一部プラグインのビルド | ほぼ必ず導入済み |

> LSP サーバー（lua_ls / ts_ls / solargraph / gopls）は mason が `~/.local/share/nvim/mason` に自動ダウンロードします。システムへのインストールは行いません。
> solargraph は `bundle exec solargraph` で起動するため、Ruby プロジェクト側に Gemfile への追加が必要です。

## 画面レイアウト（VSCode 風）

```
┌──────────────┬────────────────────────────┐
│              │  タブバー（bufferline）      │
│  Explorer    ├────────────────────────────┤
│  (<leader>e) │         エディタ            │
│  git状況付き  │      （最大2分割まで）       │
│              ├────────────────────────────┤
│              │      ターミナル（Ctrl+\）    │
└──────────────┴────────────────────────────┘
```

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| エクスプローラー（左サイドバー）を開閉 | `<leader>e` | `Ctrl+B`（サイドバー） |
| タブを移動 | `[b` / `]b` | `Ctrl+PgUp` / `Ctrl+PgDn` |
| タブを選んで閉じる | `<leader>bd` | `Ctrl+W` |
| 左右に分割 | `<leader>|` | `Ctrl+\`（分割） |
| 上下に分割 | `<leader>-` | `Ctrl+\`（分割） |
| ウィンドウ間を移動 | `Ctrl+h` `j` `k` `l` | なし（分割間の移動） |
| ウィンドウ幅を均等化 | `<leader>w=` | なし |
| ウィンドウを閉じる | `<leader>wd` または `Ctrl+w q` | `Ctrl+W` |
| 下部ターミナルを開閉 | `Ctrl+\` | `` Ctrl+` `` |
| ターミナルからノーマルモードへ抜ける | `jk` | なし |

- **エディタ領域は最大 2 分割**に制限されています（3つ目を開こうとすると自動で閉じます）。変更したい場合は `lua/config/layout.lua` の `vim.g.max_editor_windows` を編集してください。
- エディタタブは bufferline.nvim で表示されます。Explorer が開いている間はタブバーが右に寄ります。
- 下部ターミナルは toggleterm で、開いている間はフル幅のパネルになります。

## このマニュアルの使い方

- **キーを忘れたら `Space` を押す** → [which-key](https://github.com/folke/which-key.nvim) が続きの候補を表示します。各行の説明は設定ファイルの `desc` をそのまま拾っているので、常に最新です。
- `<leader>?` … いま開いているバッファで有効なキーマップ一覧
- `<leader>K` … 全キーマップ一覧
- この Markdown は「よく使うものを俯瞰する」ための静的なまとめです。網羅性より読みやすさ優先。

## はじめに：モードの概念（VSCodeにない概念）

nvimにはモードがあります。起動直後は **ノーマルモード** です。

| モード | 入り方 | 何ができる |
|---|---|---|
| ノーマルモード | `Esc` または `jk` | ナビゲーション・コマンド実行（ここが基本） |
| インサートモード | `i` | テキスト入力（VSCodeの通常状態に近い） |
| ビジュアルモード | `v` | テキスト選択 |
| ターミナルモード | `Ctrl+\` の中 | `jk` でノーマル相当（`Ctrl+\` `Ctrl+n`） |

**Leaderキー = `Space`**（以降 `<leader>` と表記）

## ファイルを開く・探す

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| ファイル名で検索して開く | `<leader>ff` | `Ctrl+P` |
| ファイル名で検索（別名） | `<leader>sf` | `Ctrl+P` |
| Gitで管理されているファイルを検索 | `<leader>gs` | `Ctrl+P`（.gitignore対応版） |
| エクスプローラー（左サイドバー）を開閉 | `<leader>e` | サイドバーのエクスプローラー |
| ファイラ（oil.nvim）を開く（親ディレクトリ） | `-` | なし |
| 開いているファイル（バッファ）一覧 | `<leader>fb` | `Ctrl+Tab` |
| 関連ファイルに切り替え（実装 ↔ テストなど） | `<leader>oo` | なし |
| 関連ファイルを新しいタブで開く | `<leader>ot` | なし |

### ファイラ（oil.nvim）の中での操作

ファイルエクスプローラーは `<leader>e`（サイドバー）と `-`（バッファ型ファイラ）の2系統があります。

ファイラはバッファなので、**普通に編集して保存(`:w`)するとファイル操作が実行されます**（作成・リネーム・削除）。

| キー | 動作 |
|---|---|
| `<CR>` | 開く（ディレクトリなら中へ） |
| `-` | 一つ上のディレクトリへ |
| `_` | カレントディレクトリ(cwd)へ |
| `g?` | ヘルプ（キー一覧） |
| `<C-c>` | ファイラを閉じる |
| `.` で始まる項目 | 隠しファイルも常に表示する設定 |

## コードを検索する

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| プロジェクト全体をGrep検索 | `<leader>sg` または `<leader>fg` | `Ctrl+Shift+F` |
| ヘルプを検索 | `<leader>fh` | なし |
| ファイル内を検索 | `/` （下方向）/ `?` （上方向） | `Ctrl+F` |
| 次の検索結果 / 前の検索結果 | `n` / `N` | `Enter` / `Shift+Enter` |
| カーソル下の単語を検索 | `*` （下）/ `#` （上） | なし |
| 検索ハイライトを消す | `Esc Esc` | なし |

### Grep して一括置換（grug-far.nvim）

検索結果がバッファに出るので、**バッファ上でテキストを直接書き換えて反映**できます。

| やりたいこと | キー |
|---|---|
| プロジェクト全体を対象に開く | `<leader>rr` |
| カーソル下の単語で開く | `<leader>rw` |
| 現在のファイルだけを対象に開く | `<leader>rf` |
| 選択範囲の文字列で開く（ビジュアルモード） | `<leader>rr` |

grug-far バッファの中での操作：

| キー | 動作 |
|---|---|
| `<leader>rp` | 置換を実行 |
| `<leader>rs` | バッファの編集内容をファイルへ反映 |
| `<leader>rq` | 結果を quickfix リストへ |
| `<leader>ro` | カーソル位置の該当箇所を開く |
| `<leader>rc` | 閉じる |
| `<leader>rt` | 検索履歴を開く |

### Git（gitsigns.nvim）

エディタ左端に変更行が表示されます（`▎` 追加 / `~` 変更 / `_` 削除）。

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| 変更一覧（Source Control）を表示 | `<leader>gS` | Source Controlパネル |
| 次の / 前の変更（hunk）へ | `]h` / `[h` | なし |
| hunkをステージ | `<leader>hs` | `+` ボタン |
| hunkを元に戻す | `<leader>hr` | `↩` ボタン |
| ファイル全体をステージ | `<leader>hS` | なし |
| ステージを取り消し | `<leader>hu` | なし |
| hunkをプレビュー | `<leader>hp` | なし |
| blame を表示 | `<leader>hb` | GitLens |
| 前回との diff を表示 | `<leader>hd` | なし |

### lazygit

| やりたいこと | キー |
|---|---|
| lazygit を開く（Snacks） | `<leader>gg` |
| lazygit を開く（lazygit.nvim） | `<leader>lg` |

lazygit は初回起動時に `~/.local/bin` へ自動導入されます（要ネットワーク）。手動で入れたい場合は任意のバイナリを `~/.local/bin/lazygit` に置いてください。

### GitHub 連携

| やりたいこと | キー | VSCodeの対応 |
|---|---|---|
| 現在のファイルをGitHubで開く | `<leader>gf` | なし |
| 選択行をGitHubでハイライト表示 | `<leader>gf`（ビジュアルモード） | なし |
| GitHubリポジトリのトップを開く | `<leader>gr`（ノーマルモード）| なし |
| GitHubでブラウズ（ブランチ選択あり） | `<leader>gB` | なし |

> SSH環境ではブラウザを起動できないため、`gx` は URL を `+` レジスタにコピーして通知します（ローカル側に手動で貼り付けて開く運用向け）。

## Vim / Neovim の標準キー（設定不要・よく使うもの）

プラグインではなく Vim 本体の機能。詳細は `:help quickref`（vimdoc-ja 導入済みなので日本語）。

### 移動（ノーマルモード）

| キー | 動作 |
|---|---|
| `h` `j` `k` `l` | 左 下 上 右 |
| `w` / `b` | 次の単語の先頭 / 前の単語の先頭 |
| `e` | 単語の末尾 |
| `0` / `^` / `$` | 行頭 / 行の最初の非空白 / 行末 |
| `gg` / `G` | ファイルの先頭 / 末尾 |
| `{` / `}` | 段落単位で上 / 下 |
| `%` | 対応する括弧へ |
| `Ctrl+u` / `Ctrl+d` | 半画面 上 / 下スクロール |
| `f{文字}` / `t{文字}` | 行内でその文字へ / その手前へ |
| `{数字}G` または `:{数字}` | 指定行へ |
| `H` / `M` / `L` | 画面の 上 / 中央 / 下へ |

### 編集（ノーマルモード）

| キー | 動作 |
|---|---|
| `i` / `a` | カーソル前 / 後ろ から挿入 |
| `I` / `A` | 行頭 / 行末 から挿入 |
| `o` / `O` | 下 / 上 に空行を作って挿入 |
| `x` / `dd` | 1文字削除 / 1行削除 |
| `dw` / `d$` / `diw` | 単語削除 / 行末まで削除 / 単語まるごと削除 |
| `cw` / `ciw` / `ci"` | 単語を変更 / 単語まるごと変更 / `"` の中を変更 |
| `yy` / `yw` | 1行ヤンク（コピー）/ 単語ヤンク |
| `p` / `P` | カーソルの後 / 前 に貼り付け |
| `r{文字}` | 1文字置換 |
| `u` / `Ctrl+r` | アンドゥ / リドゥ |
| `.` | 直前の編集を繰り返す |
| `>>` / `<<` | インデント 増 / 減 |
| `J` | 次の行を連結 |
| `gcc` / `gc`（選択中）| 行コメントのトグル（Neovim標準） |

### 検索・置換

| キー / コマンド | 動作 |
|---|---|
| `:%s/old/new/g` | ファイル全体を置換 |
| `:%s/old/new/gc` | 置換（1件ずつ確認） |
| `:s/old/new/g` | 現在行のみ置換 |

### ウィンドウ・バッファ・タブ

| キー / コマンド | 動作 |
|---|---|
| `<leader>|` / `<leader>-` | 左右 / 上下 に分割（本設定追加） |
| `Ctrl+w` `h/j/k/l` | 分割したウィンドウ間を移動（`Ctrl+h/j/k/l` 単体でも可） |
| `Ctrl+w` `q` | ウィンドウを閉じる |
| `Ctrl+w` `=` | ウィンドウサイズを均等化 |
| `:bn` / `:bp` / `[b` / `]b` | 次 / 前 のバッファ |
| `:bd` | バッファを閉じる |
| `:tabnew` / `gt` / `gT` | 新規タブ / 次タブ / 前タブ |

### ビジュアルモード

| キー | 動作 |
|---|---|
| `v` / `V` / `Ctrl+v` | 文字選択 / 行選択 / 矩形選択 |
| `y` / `d` / `c` | 選択範囲を コピー / 削除 / 変更 |
| `>` / `<` | 選択範囲をインデント 増 / 減 |
| `=` | 選択範囲を自動整形 |

## ファイル構成

```
~/.config/nvim/
├── init.lua                  # エントリーポイント（基本オプション・キーマップ）
├── lazy-lock.json            # プラグインのバージョン固定
└── lua/
    ├── config/
    │   ├── lazy.lua          # lazy.nvim のブートストラップ
    │   ├── layout.lua        # VSCode風レイアウト（最大2分割・ウィンドウ移動等）
    │   └── lazygit.lua       # lazygit の自動導入
    └── plugins/              # プラグインごとの設定（1ファイル1プラグイン）
```
